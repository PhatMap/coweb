# Contributing to CoWeb

Keep changes scoped and preserve the Responses, MCP, model and tunnel contracts.
Read the architecture and identity migration notes before changing runtime identifiers.

Use the pinned Bun version and frozen lockfiles. Run `bun run verify` before proposing
changes. Authenticated browser/tool behavior and packaged installers need separate
manual validation; record unexecuted checks honestly.

Never include cookies, keys, browser profiles, personal paths or raw diagnostic bundles
in an issue or change. Preserve LICENSE, NOTICE.md and third-party notices. No release
publishing automation or repository URL is configured for this baseline.
